# Data Pipeline

Static datasets are **pre-computed** at build time by `prepare_data.py`.
The frontend loads them at module scope — no backend, no DB, no SSR data fetch.

## Files

| File | Source | Generated by |
|---|---|---|
| `donne_es2026.xlsx` | provided (Agence ORE / data.gouv.fr) | manual download |
| `insee_population_departements.csv` | INSEE | manual download (or fallback used) |
| `departments.json` | derived | `prepare_data.py` |
| `geojson.json` | derived | `prepare_data.py` |
| `anomalies.json` | derived | `prepare_data.py` |
| `clusters.json` | derived | `prepare_data.py` |
| `predictions.json` | derived | `prepare_data.py` |

## Regenerate

```bash
cd data
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python prepare_data.py --verify
```

Should complete in <60 seconds. All outputs deterministic (`random_state=42`).

## Schema versioning

If you change the script's output schema, also update `lib/data.types.ts`
(generated by the script automatically). Run `npm run typecheck` afterward.

## Country extensibility

To add a country (UK, Germany, etc.), create:
- `data/countries/<iso>.config.json` with the column mapping
- A same-schema source file
- Run `python prepare_data.py --country=<iso>`

The pipeline accepts the config and outputs country-namespaced JSONs.
